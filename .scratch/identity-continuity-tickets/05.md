## What to build

Opening Review IDs computes occlusion bouts, proximity risks, and decisive proposed switch markers from current raw tracklets — including videos that were detected before the new live association. Raw is never rewritten. Already accepted identities stay accepted.

Proposed switch markers appear as distinct timeline ticks and a compact list. Accept promotes a proposal to a switch marker (N-way permutation of involved slots). Dismiss persists on the identity package and is not applied on save. Save still publishes accepted identities from the human-owned switch-marker list (empty list still means accept raw).

Weaker bouts stay timeline hints. Proposals that match a switch marker already on the list are not shown. Re-detect / new raw clears proposals and dismissals. Manual Swap IDs stays a two-identity swap.

## Acceptance criteria

- [ ] Opening Review IDs (or an equivalent package load) derives occlusion bouts, proximity risks, and proposed switch markers from raw only; raw files are unchanged.
- [ ] A proposed switch marker is emitted only when rematch is decisive (typically at freeze-lift, or a leftover chase/split error). Weaker bouts are timeline risk only.
- [ ] A synthetic wrestle with several freeze-lifts can produce multiple proposed switch markers, not only one at the final exit.
- [ ] Proposals persist on the identity package; reopen still shows undismissed ones.
- [ ] Dismiss persists across reopen and is not a switch marker; save does not apply dismissed items.
- [ ] Accept adds the mapping to the switch-marker list and updates the preview; Accept supports an N-way permutation. Manual Swap IDs remains two-ID.
- [ ] Proposals that match an existing switch marker are suppressed.
- [ ] Computing proposals does not un-accept an already accepted package. Accepting new proposals and saving still warns if downstream artifacts exist.
- [ ] Re-detect / new raw clears proposals and dismissals (same new tracking world as switches).
- [ ] Timeline distinguishes occlusion bouts from proximity risks, and proposed switch markers from human switch markers.
- [ ] Save with zero accepted proposals still means the user accepts raw.
